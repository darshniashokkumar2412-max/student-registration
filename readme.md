# Student Registration Form

A simple **Student Registration Form** created using basic HTML. This project is suitable for beginners who are learning HTML forms and input elements.

## 📌 Project Description

The Student Registration Form collects basic student information such as:

* Full Name
* Email
* Password
* Phone Number
* Date of Birth
* Gender
* Course
* Address
* Profile Photo

It also includes **Register** and **Clear** buttons.

## 🛠️ Technologies Used

* HTML5

## 📂 Project Structure

```text
Student-Registration-Form/

```

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder.
3. Double-click `registration.html`.
4. The registration form will open in your web browser.

## ✨ Features

* Simple and clean registration form
* Text input fields
* Email and password fields
* Phone number input
* Date picker for date of birth
* Gender selection using radio buttons
* Course selection using a dropdown menu
* Address textarea
* Photo upload option
* Terms and conditions checkbox
* Register and Clear buttons
